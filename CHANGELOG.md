# Changelog

## Versiones

### [1.0.0] - 2026-07-12

#### Agregado

- Desarrollo de AgroPredict como Plataforma Web Progresiva (PWA).
- Integración de información agrícola y climática para la estimación del rendimiento de cultivos.
- Implementación de un modelo de Machine Learning para apoyar la toma de decisiones agrícolas.
- Funcionamiento en modo online y offline.
- Sincronización de simulaciones cuando se recupera la conexión a Internet.
- Documentación técnica del proyecto.
- Organización del repositorio conforme a la estructura solicitada para la convocatoria.
